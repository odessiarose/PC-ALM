# PC-ALM
The following repository contains the code for PC-ALM (Augmented Lagrangian Predictive Coding) as explained by [Sakana AI](https://github.com/sakanaai) in this [paper](https://arxiv.org/pdf/2605.31022). You can also find the paper in the `./paper` directory.

To check the code, you can have a look at the `algo.ipynb` notebook in the `./notebook_exp` folder.
